CATATAN REFLEKSI - LANDING PAGE IMMANUEL LIBRARY

1. Apa keuntungan memisahkan header dan footer menjadi file component tersendiri,
   dibandingkan menuliskannya langsung berulang-ulang di index.php?

   Dengan memisahkan header dan footer ke components/landing/header.php dan
   components/landing/footer.php, markup yang sama cukup ditulis satu kali lalu
   disertakan ke halaman mana pun dengan require_once. Jika ada perubahan, misalnya
   menambah menu navigasi atau mengganti teks hak cipta, cukup mengubah satu file dan
   seluruh halaman yang memakainya ikut berubah. Hal ini mengurangi risiko tampilan
   tidak konsisten karena lupa mengubah salah satu salinan. File index.php juga menjadi
   lebih pendek dan fokus pada isi halaman (hero, statistik, fitur), sehingga lebih mudah
   dibaca dan dirawat.

2. Bagian mana pada halaman-halaman admin (Buku, Kategori, Penulis, Pengguna, Profil)
   yang mengalami masalah yang sama seperti header/footer sebelum dipisah?

   Bagian sidebar (elemen <aside> berisi menu Beranda, Buku, Kategori, Penulis, Pengguna,
   dan Profil Saya) dan topbar (elemen <header> berisi judul halaman serta info pengguna)
   ditulis ulang secara identik di 14 file halaman admin. Akibatnya, jika satu menu
   sidebar diubah atau ditambah, kita harus mengedit 14 file satu per satu dan mudah ada
   yang terlewat. Topbar juga hanya berbeda pada judul dan subjudulnya, sehingga lebih
   tepat dijadikan satu component yang menerima variabel $pageTitle dan $pageSubtitle.
   Selain itu, data pada halaman admin masih ditulis sebagai array mentah di tiap file,
   bukan diambil dari satu sumber (repository function).
=======
1. Apa keuntungan memisahkan header dan footer menjadi file component tersendiri?

Memisahkan header dan footer menjadi component membuat kode lebih rapi dan mudah dikelola. Jika terdapat perubahan pada header atau footer, kita hanya perlu mengubah satu file tanpa mengedit setiap halaman. Selain itu, component dapat digunakan kembali sehingga mengurangi pengulangan kode dan membuat struktur project lebih efisien.

2. Bagian mana pada halaman admin yang mengalami masalah sama seperti header dan footer sebelum dipisah?

Bagian yang mengalami masalah serupa adalah sidebar dan topbar pada halaman admin. Sebelumnya, kedua bagian tersebut ditulis berulang kali pada setiap halaman, seperti Buku, Kategori, Penulis, Pengguna, dan Profil. Dengan memisahkannya menjadi component, kode menjadi lebih konsisten dan lebih mudah diperbarui.
